# Roadmap

## Phase 1

- Scaffold repo and app shell
- Build playful landing page
- Add \`/chess\` and \`/checkers\` routes
- Add global theme switcher with multiple presets
- Create stable docs and tracking files
- Verify lint and build locally

## Phase 2

- Make checkers the first playable game
- Extract shared board framework and local game state model
- Add reset flow, turn state, move feedback, and crown support
- Add stronger test coverage

## Phase 3

- Add playable chess
- Evaluate battle-tested chess rules library versus custom implementation
- Persist preferences and in-progress local sessions
- Add deployment polish and preview workflow

## Working Model

- \`Plutus\`: orchestration, roadmap, task tracking, decisions
- \`Hephaestus\`: implementation
- \`Athena\`: review, debugging, architectural challenge
