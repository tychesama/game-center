# Project Memory

## Summary

GameCenter started as a phased trial project for an agent-driven workflow. The initial target is a deployable frontend shell for multiple board games, beginning with chess and checkers.

## Decisions

- Use a frontend-first architecture
- Keep the site playful, not sterile
- Build a theme system that changes more than color
- Treat checkers as the saner first playable game
- Keep future game rules separate from React UI
